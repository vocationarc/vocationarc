VocationArc brings resume creation, application writing and job-search organization into one career platform.

## What you can do

- Create and edit resumes, then export them as PDFs.
- Get ATS insights and compare a resume with a job description.
- Draft tailored cover letters and application messages.
- Save opportunities and track job applications.
- Share your work through public resume and profile links.
- Use career guidance through Compass.

## Across your job search

Start on the web, capture opportunities with the browser extension, and continue your job search with the mobile experience. Visit the website for current availability.

## A new name for the same journey

CraftMyResume is becoming **VocationArc**. The rebrand keeps the existing product offering and approved visual theme.
